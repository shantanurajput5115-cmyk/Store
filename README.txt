RAJ / ATELIER & ESSENTIALS — Shantanu Raj

GET STARTED
Open RAJ-Atelier.html in a modern browser. No installation or build step is required. Internet access is needed for Unsplash photography and Google Fonts; system fonts work offline.

FEATURES
Responsive overview, inventory, collections, order tracking, owner story, search, category filters, product creation/editing, unique SKU checks, stock validation, order creation, cancellation with stock restoration, and a seven-day order-value chart.

DATA & LIMITATIONS
Products, customers, prices, and orders are fictional sample data. Photography is illustrative and externally hosted, not bundled or guaranteed to match the exact products. Data is saved under raj-atelier-v1 in your browser localStorage. File-URL storage behavior depends on the browser; use the same browser and file location, or serve the page with a local web server for more consistent behavior. This is a front-end management demo, not a secure production ecommerce system. It does not include authentication, a database, checkout, payment processing, tax calculations, shipping integrations, or multi-user synchronization. Do not enter sensitive customer information. Clearing browser storage deletes saved changes.

USAGE
Add product: create a product with a unique SKU, price, stock, and optional HTTPS photo URL.
Edit product: use the Edit product button on a product card.
Create order: choose a product and available quantity; stock decreases immediately.
Update status: choose Processing, Shipped, Delivered, or Cancelled in the order table. Cancellation is final and restores stock once.
Revenue counts delivered orders only. The chart shows non-cancelled order value by creation date. Initial seeded stock represents currently available stock after sample orders.
